Quick Start

Get Chat Agent Relay running in 5 minutes. Install, pick a channel, connect an agent, and start relaying messages.

Install

Clone the repository and install dependencies with Bun:

git clone https://github.com/ChatAgentRelay/ChatAgentRelay.git
cd ChatAgentRelay
bun install

This pulls all workspace packages so the car CLI is immediately available from packages/server.

Pick a channel

Channels are chat-platform adapters. Choose one to start:

💬
Slack
Socket Mode, threads, reactions, streaming, slash commands.
🎮
Discord
Gateway connection, embeds, slash commands, guild control.
🌐
WebChat
HTTP-based, no setup needed. Great for testing.

The simplest option is WebChat — no external app setup required:

car channel add web --type=webchat

Pick an agent

Agents are the AI backends that respond to messages. CAR supports multiple protocols:

🔗
A2A
Google’s Agent-to-Agent protocol with HITL and streaming.
🧠
LangGraph
LangGraph Platform with threads and interrupt/resume.
📡
HTTP
Any HTTP endpoint. Custom headers, body, response extraction.
⌨️
ACP
Agent Client Protocol for coding agents via subprocess.

The simplest option is an HTTP agent — any endpoint that returns JSON:

car agent add my-bot --type=http --endpoint=http://localhost:8080

Set a route

Routes decide which agent handles each incoming message. Set a default route to send everything to your agent:

car route add --default --agent=my-bot
Multi-agent routing You can register multiple agents and use pattern-based or channel-based rules to route messages. See Multi-Agent Routing.

Start

Launch the relay server:

car start

The server starts on port 3000 by default. Verify with:

curl http://localhost:3000/api/health
Encrypt secrets at rest Set CAR_ENCRYPTION_KEY before adding channels or agents so tokens and API keys are stored with AES-256-GCM encryption in the SQLite config database.
