Architecture

Chat Agent Relay is a standard relay layer between chat platforms and agents. This overview explains the main boundaries, the canonical message path, and how the current repository is organized around them.

Architecture summary

The relay is centered on one canonical message path:

chat platform ingress
  → channel adapter verification and canonicalization
  → canonical event enters middleware
  → governance
  → route decision
  → agent invocation via A2A
  → canonical outbound intent
  → delivery
  → append-only ledger / replay / audit

Channel-specific behavior and agent-specific behavior stay at the boundaries. Inside the relay, CAR operates on canonical events so the message path remains consistent across integrations.

Boundary model

Channel-side boundary

Channel adapters receive provider-native traffic, verify it where applicable, canonicalize it into CAR events, and translate outbound canonical intent back into provider-native delivery behavior.

CAR core

CAR owns canonical event semantics, governance on the message path, route decisions, delivery orchestration, replay, and auditability.

Agent-side boundary

CAR uses A2A as the standard agent-side protocol boundary. Remote agent runtimes keep ownership of their internal execution model, private memory, tools, and framework-specific state.

System view

Chat Platforms → Channel Adapters → Middleware / Pipeline → Agent Adapter (A2A) → Agents
                                      ↓
                              Append-Only Ledger
                                      ↓
                             Replay / Audit / Query

Key principles

  • Canonical events — provider-native input is normalized into a stable internal contract.
  • Governed message path — governance runs before routing and before delivery.
  • Append-only ledger — key outcomes remain replayable and auditable.
  • A2A at the agent boundary — CAR stays focused on the relay path rather than becoming a broad runtime abstraction layer.
  • Boundary discipline — provider-native detail and runtime-private state stay at the edges instead of becoming CAR's source of truth.
