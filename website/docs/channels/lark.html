Lark / 飞书

Connect Lark (飞书) bots to your AI agents. One adapter covers both the international Lark platform and the Chinese 飞书 platform. Supports event subscription, streaming via message editing, automatic token management, and group/DM conversations.

Prerequisites

Create a Lark/Feishu application:

  1. Create an app at Lark Developer Console (international) or 飞书开放平台 (China).
  2. Enable bot capabilities under Features → Bot.
  3. Add permissions:
    • im:message — send and receive messages
    • im:message.group_at_msg — receive @mentions in groups
    • im:resource — access files and images
    • contact:user.id:readonly — user identification
  4. Subscribe to events — add im.message.receive_v1 event, choose WebSocket or webhook mode.
  5. Publish the app and copy the App ID and App Secret.

Add to CAR

car channel add my-lark \
  --type=lark \
  --app-id=cli_xxx \
  --app-secret=yyy
One adapter, two platforms The same channel-lark adapter works with both Lark (international) and 飞书 (China). The API endpoints are the same; only the developer console URL differs.

Features

Automatic token management

The sender automatically obtains and caches a tenant_access_token using the app credentials. Tokens are refreshed transparently before expiry — no manual token management needed.

Streaming (progressive update)

When the connected agent supports streaming, CAR sends an initial message and progressively edits it via the PATCH /im/v1/messages/{message_id} API as tokens arrive.

Group and DM support

The adapter handles both P2P (direct message) and group conversations. The chat_type (p2p/group) is preserved in provider_extensions.

@Mentions

When users @mention the bot in a group, the mention metadata (user IDs and names) is preserved in provider_extensions.lark.mentions.

Event deduplication

The idempotency key is lark-{event_id} from the event header, ensuring duplicate event deliveries are handled correctly.
