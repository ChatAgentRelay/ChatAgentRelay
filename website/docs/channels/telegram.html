Telegram

Connect Telegram bots to your AI agents using the Telegram Bot API. Supports webhook-based message ingestion, progressive streaming via message editing, bot commands, and group/private chat handling.

Prerequisites

Create a Telegram bot via @BotFather:

  1. Create a new bot — send /newbot to @BotFather, choose a name and username.
  2. Copy the bot token — BotFather will provide a token like 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11.
  3. Set webhook URL — point the webhook to your CAR server endpoint (CAR handles this automatically on startup).
  4. (Optional) Set commands — use /setcommands in BotFather to register slash commands for autocomplete.

Add to CAR

Register the Telegram channel with the car CLI:

car channel add my-telegram \
  --type=telegram \
  --bot-token=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
Tokens are encrypted at rest Bot tokens are stored with AES-256-GCM encryption when CAR_ENCRYPTION_KEY is set.

Features

Streaming (progressive update)

When the connected agent supports streaming, CAR sends an initial placeholder message and then progressively edits it using the Telegram editMessageText API as new tokens arrive. Users see the response build up in real time.

Bot commands

Messages starting with / and containing a bot_command entity are canonicalized as command.received events. The command name and arguments are extracted automatically:

/summarize last meeting notes
→ command_name: "summarize"
→ text: "last meeting notes"

Group and private chats

The adapter handles both group chats and private (DM) conversations. In groups, the bot typically responds to @mentions or commands. The chat_type (private, group, supergroup, channel) is preserved in provider_extensions.

Message editing

The sender supports both sendMessage for new replies and editMessageText for updating existing messages. This enables streaming and correction workflows.

Configuration options

Option CLI flag Required Description
botToken --bot-token Yes Bot API token from @BotFather

Provider extensions

The following Telegram-specific data is preserved in provider_extensions.telegram:

FieldTypeDescription
update_idnumberTelegram update sequence number
message_idnumberMessage ID within the chat
chat_idnumberChat identifier
chat_typestringOne of: private, group, supergroup, channel

Idempotency

The idempotency key is tg-{update_id}, ensuring duplicate webhook deliveries from Telegram are correctly deduplicated.
