HTTP API

Full REST API reference for managing and querying Chat Agent Relay. All endpoints are available when the server is running (default http://localhost:3000).

Health

GET /api/health

Liveness check. Returns server status and uptime.

curl -s http://localhost:3000/api/health

Response 200 OK

{
  "status": "ok",
  "uptime": 3600,
  "version": "1.0.0"
}

Events

GET /api/events/:id

Retrieve a single event by its event_id.

curl -s http://localhost:3000/api/events/evt_a1b2c3d4

Response 200 OK

{
  "event_id": "evt_a1b2c3d4",
  "event_type": "message.received",
  "timestamp": "2025-03-15T10:30:00.000Z",
  "correlation_id": "corr_x9y8z7",
  "causation_id": null,
  "conversation_id": "C123456",
  "channel": "my-slack",
  "payload": { "text": "Hello, agent!", "sender_id": "U987654" }
}

GET /api/conversations/:id/events

List all events for a conversation, ordered chronologically.

curl -s http://localhost:3000/api/conversations/C123456/events

Response 200 OK

[
  { "event_id": "evt_001", "event_type": "message.received", ... },
  { "event_id": "evt_002", "event_type": "policy.decision.made", ... },
  { "event_id": "evt_003", "event_type": "route.decision.made", ... },
  ...
]

GET /api/correlations/:id/events

List all events sharing a correlation_id (a single request chain).

curl -s http://localhost:3000/api/correlations/corr_x9y8z7/events

Response 200 OK — same format as conversation events.

Audit

GET /api/conversations/:id/audit

Human-readable audit trail for a conversation. Returns events with explanations of what happened and why.

curl -s http://localhost:3000/api/conversations/C123456/audit

Response 200 OK

{
  "conversation_id": "C123456",
  "entries": [
    {
      "event_id": "evt_001",
      "event_type": "message.received",
      "explanation": "Message received from user alice in channel my-slack"
    },
    {
      "event_id": "evt_002",
      "event_type": "policy.decision.made",
      "explanation": "Policy allowed: no matching deny rules"
    },
    ...
  ]
}

Agents

GET /api/agents

List all registered agents.

curl -s http://localhost:3000/api/agents

Response 200 OK

[
  { "name": "primary", "type": "a2a", "enabled": true },
  { "name": "coder", "type": "langgraph", "enabled": true },
  { "name": "fallback", "type": "http", "enabled": false }
]

POST /api/agents

Register a new agent.

curl -X POST http://localhost:3000/api/agents \
  -H "Content-Type: application/json" \
  -d '{
    "name": "support",
    "type": "openai",
    "config": {
      "api_key": "sk-...",
      "model": "gpt-4o"
    }
  }'

Response 201 Created

{ "name": "support", "type": "openai", "enabled": true }

PUT /api/agents/:name

Update an existing agent’s configuration.

curl -X PUT http://localhost:3000/api/agents/support \
  -H "Content-Type: application/json" \
  -d '{
    "config": { "model": "gpt-4o-mini" }
  }'

Response 200 OK

DELETE /api/agents/:name

Remove an agent.

curl -X DELETE http://localhost:3000/api/agents/support

Response 204 No Content

POST /api/agents/:name/enable

Enable a disabled agent.

curl -X POST http://localhost:3000/api/agents/fallback/enable

Response 200 OK

POST /api/agents/:name/disable

Disable an agent without removing it.

curl -X POST http://localhost:3000/api/agents/fallback/disable

Response 200 OK

Channels

GET /api/channels

List all registered channels.

curl -s http://localhost:3000/api/channels

Response 200 OK

[
  { "name": "my-slack", "type": "slack", "enabled": true },
  { "name": "web", "type": "webchat", "enabled": true }
]

POST /api/channels

Register a new channel.

curl -X POST http://localhost:3000/api/channels \
  -H "Content-Type: application/json" \
  -d '{
    "name": "support-discord",
    "type": "discord",
    "config": {
      "bot_token": "MTIz...",
      "app_id": "123456"
    }
  }'

Response 201 Created

PUT /api/channels/:name

Update a channel’s configuration.

curl -X PUT http://localhost:3000/api/channels/my-slack \
  -H "Content-Type: application/json" \
  -d '{
    "config": { "mention_only": true }
  }'

Response 200 OK

DELETE /api/channels/:name

Remove a channel.

curl -X DELETE http://localhost:3000/api/channels/support-discord

Response 204 No Content

POST /api/channels/:name/enable

Enable a disabled channel.

curl -X POST http://localhost:3000/api/channels/my-slack/enable

Response 200 OK

POST /api/channels/:name/disable

Disable a channel without removing it.

curl -X POST http://localhost:3000/api/channels/my-slack/disable

Response 200 OK

Routes

GET /api/routes

List all routing rules.

curl -s http://localhost:3000/api/routes

Response 200 OK

[
  { "id": 1, "type": "channel", "match": "support-discord", "agent": "support" },
  { "id": 2, "type": "pattern", "match": "^/code", "agent": "coder" },
  { "id": 3, "type": "default", "match": "*", "agent": "primary" }
]

POST /api/routes

Add a routing rule.

curl -X POST http://localhost:3000/api/routes \
  -H "Content-Type: application/json" \
  -d '{
    "type": "pattern",
    "match": "^/translate",
    "agent": "translator"
  }'

Response 201 Created

{ "id": 4, "type": "pattern", "match": "^/translate", "agent": "translator" }

DELETE /api/routes/:id

Remove a routing rule by its numeric ID.

curl -X DELETE http://localhost:3000/api/routes/4

Response 204 No Content

Config

GET /api/config

List all key-value configuration entries.

curl -s http://localhost:3000/api/config

Response 200 OK

[
  { "key": "log_level", "value": "debug" },
  { "key": "max_retries", "value": "3" }
]

PUT /api/config/:key

Set a configuration value.

curl -X PUT http://localhost:3000/api/config/log_level \
  -H "Content-Type: application/json" \
  -d '{ "value": "info" }'

Response 200 OK

DELETE /api/config/:key

Delete a configuration entry.

curl -X DELETE http://localhost:3000/api/config/log_level

Response 204 No Content
